## 🌌 关于 Horae

**Horae**（荷莱）是希腊神话中掌管四季、时序与自然节律的女神之名。正如 Horae 女神守护着时间的秩序，本项目以中国二十四节气为脉络，探索千年时间智慧在当代气候变化下的回响。

二十四节气于 2016 年被列入**联合国教科文组织人类非物质文化遗产代表作名录**，是中国人通过观察太阳周年运动而形成的时间知识体系。在全球变暖的今天，节气所描述的物候正在发生深刻变化——春天来得更早，冬天越来越暖。

**Horae · 节气志**用数据可视化的方式，让古人的节气智慧与当代气候数据展开一场跨越千年的对话。

## ✨ 核心特性

### 🎨 沉浸式视觉体验
- **动态粒子背景**：70+ 发光粒子与连线网络，颜色随季节主题实时变化
- **四季主题色切换**：滚动/切换节气时，全局主题色在春绿、夏红、秋橙、冬蓝间平滑过渡
- **新中式深色美学**：金色点缀 + 毛玻璃卡片 + 发光效果，东方美学与现代设计融合
- **中国传统色库**：24 节气各对应一个中国传统色（天青、黛蓝、竹青、朱砂、月白……）

### 🎡 交互式节气轮盘
- **可拖拽旋转**：鼠标/触摸拖动轮盘，实时吸附到最近节气
- **北斗七星装饰**：轮盘顶部绘制北斗七星连线，呼应古人观象授时
- **传统色点环**：内圈 24 个节气对应传统色圆点
- **点击跳转**：点击扇区自动旋转并展示该节气详情

### 📖 24 节气深度内容
每个节气包含完整的文化与数据维度：
- 📜 **经典诗词**：24 首节气相关古诗词（含标题、作者、内容）
- 🌿 **七十二候**：每节气三候，源自《月令七十二候集解》
- 📖 **古籍原文**：《月令七十二候集解》原文引用
- 🌡️ **古今温度对比**：1976 vs 2025 平均温度 + 50 年趋势图
- 🌗 **昼夜时长**：渐变进度条 + 日出日落时间
- 🍜 **时令饮食**：春饼、青团、夏至面、饺子等节气食俗
- 🌸 **节气花卉**：梅花、桃花、牡丹、桂花、腊梅等
- 🎨 **传统色卡**：色名 + HEX 色值 + 色块预览
- 🤖 **AI 古今对话**：每个节气配 AI 解读气候变化影响

### 📊 丰富的数据可视化
基于 Apache ECharts 的 6+ 种图表：
- 二十四节气温升幅度排行（渐变柱状图）
- 节气-月份温度热力图（7 色渐变）
- 四季温升对比（环形饼图）
- 古今温度全年对比（双折线面积图）
- 二十四节气昼夜时长分布（堆叠柱状图）
- 单节气 50 年温度趋势（平滑面积图）
- 单节气 6 维气候雷达图

### 🤖 AI 节气问答
- 内置 AI 节气顾问，解答节气习俗、物候变化、气候趋势
- 6 个快捷问题一键提问
- 支持自由输入，关键词智能匹配

## 📊 数据说明

### 数据来源
- **物候数据**：源自《月令七十二候集解》（元代·吴澄编撰）
- **节气日期与太阳黄经**：天文学标准数据
- **气候数据**：基于公开气象资料的趋势模拟（1976–2025）
- **诗词数据**：公开领域古典诗词
- **传统色**：参考《中国传统色》系列

### 数据字段（每节气）

```javascript
  longitude: 315,             // 太阳黄经

    first: "东风解冻",

    third: "鱼陟负冰"
  },
  ancient: "...",             // 古籍原文
  modernTemp: 3.2,            // 当代平均温度
  oldTemp: 1.8,               // 50年前平均温度
  tempChange: 1.4,            // 升温幅度
  humidity: 55,               // 平均湿度
  precipitation: 15,          // 降水量
  phenologyChange: "...",     // 物候变化描述

```

### ⚠️ 数据声明
气候数据为基于公开气象趋势的**模拟数据**，用于数据可视化演示，不代表精确的气象观测值。如需学术研究，请引用权威气象数据集（如中国气象数据网、NOAA、CRU 等）。

## 🎯 设计理念

### 古今对话
项目的核心叙事是"古今对话"——古人通过观察自然总结出二十四节气，今人通过数据观测发现气候正在变化。每一个节气页面都在呈现这种对话：古籍原文 vs 当代数据，传统物候 vs 变化趋势。

### 东方美学
- 深色背景 + 金色点缀，呼应古籍宣纸与烫金工艺
- 中文衬线字体（Noto Serif SC），保持文化质感
- 中国传统色体系，24 节气 24 色
- 粒子背景如星象，呼应古人观象授时

### 交互叙事
- 轮盘的旋转 = 时间的流转
- 季节主题色的切换 = 四时的更迭
- 卡片的展开 = 知识的探索
- 数据图表的呈现 = 真相的揭示

## 🔧 自定义与扩展

### 修改节气数据
编辑 `js/data.js` 中的 `solarTerms` 数组和 `termExtras` 对象。

### 修改主题色
编辑 `css/style.css` 中的 `:root` 自定义属性：
```css
:root {
  --spring: #8bc34a;   /* 春 */
  --summer: #ef5350;   /* 夏 */
  --autumn: #ffa726;   /* 秋 */
  --winter: #42a5f5;   /* 冬 */
  --gold: #d4a853;     /* 金 */
}
```

### 接入真实气象数据
1. 从中国气象数据网或 NOAA 获取真实数据
2. 替换 `js/data.js` 中的 `modernTemp`、`oldTemp` 等字段
3. 修改 `common.js` 中 `initTrendChart` 的数据生成逻辑

### 接入真实 AI API
当前 AI 问答为本地关键词匹配。如需接入真实大模型：
1. 在 `chat.html` 的 `sendMsg` 函数中替换响应逻辑
2. 调用 OpenAI / 文心一言 / 通义千问等 API
3. 注意 API Key 安全（建议通过后端代理）
